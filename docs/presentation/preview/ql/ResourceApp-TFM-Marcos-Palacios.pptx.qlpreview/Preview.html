Especificación técnica

API jerárquica y consistencia

Las rutas reflejan el dominio y concentran validaciones de pertenencia, duplicados, borrado lógico y transacciones.

Especificación técnica

ResourceApp · Marcos Palacios

15

Ruta representativa

POST /api/v1/projects/{projectId}/pages/{pageId}/versions/{pageVersionId}/resources/{resourceId}/automatic-translations

 

GET  /api/v1/projects/{projectId}/pages/{pageId}

POST /api/v1/projects/{projectId}/pages/{pageId}/versions

PATCH /api/v1/projects/{projectId}/pages/{pageId}/versions/{pageVersionId}

Pertenencia

Cada operación verifica que proyecto, página y versión pertenecen al mismo contexto solicitado.

Duplicados

Se bloquean claves repetidas y conflictos de recursos para mantener consistencia funcional.

Soft delete

El borrado lógico preserva trazabilidad y evita perder historial útil de edición.

Transacciones

Los cambios críticos, como traducciones automáticas, se completan o revierten de forma atómica.

Especificación técnica

Seguridad y frontera de confianza

La solución combina autenticación delegada, tokens propios y aislamiento de secretos en el backend y en Azure.
